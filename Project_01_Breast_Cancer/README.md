# Breast Cancer Classification

A Machine Learning project for classifying breast tumors
as malignant or benign using the Breast Cancer Wisconsin
(Diagnostic) dataset.

## 1. Project Overview

The objective of this project is to explore a medical
dataset and develop a classification model capable of
distinguishing between malignant and benign tumors.

The project includes data exploration, preprocessing,
model training, and evaluation.

## 2. Dataset

- **Name:** Breast Cancer Wisconsin (Diagnostic)
- **Source:** Scikit-learn
- **Samples:** 569
- **Features:** 30 numerical features
- **Target:** Diagnosis (malignant or benign)
- **Classes:**
  - 0: Malignant
  - 1: Benign

The dataset contains measurements of cell nuclei,
including radius, texture, perimeter, area, smoothness,
compactness, concavity, symmetry, and fractal dimension.

Each measurement is represented by its mean, standard
error, and worst value.

## 4. Project Workflow

The project follows these main steps:

1. **Data Loading:** Load the dataset using Scikit-learn.
2. **Data Exploration:** Examine the dataset structure,
   statistical information, and feature distributions.
3. **Data Visualization:** Use charts to understand
   relationships between features and target classes.
4. **Data Preprocessing:** Prepare the data for
   machine learning.
5. **Model Training:** Train classification algorithms.
6. **Model Evaluation:** Evaluate model performance
   using appropriate metrics.
